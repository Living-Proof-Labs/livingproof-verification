Verification index and history

A cleaner, human-readable view of the docs site index and run history. Results first; evaluators stay quiet and only failures speak. The pages use the same visual language as the capability report.

Open the standalone pages to review them at desktop or mobile width. Current live screenshots and the proposed PNGs are in screens/. The written spec is in README.md.

Index mock History mock Spec

  • CI run is a text link, no run number. Checksums are dropped from the list.
  • A release tag is shown when one exists; otherwise a short commit SHA.
  • Times are relative, with the local date on the tooltip (Australia/Sydney).
  • Failing evaluators are linked chips using the stored title exactly (Scenario, not “Scenario Evaluator”). Each human reviewer is a chip of their own.
  • The list is continuous, with no pagination.
